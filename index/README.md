# ClearCut Fast Folder Background Remover

GitHub Pages-ready, client-side, non-AI background remover.

- Select a folder with up to 250 images.
- Processes 6 images at a time to reduce browser freezing.
- No image uploads to a server.
- Download all processed PNGs as a ZIP.
- Best results with reasonably uniform backgrounds.

## GitHub Pages
Upload `index.html` to a repository, then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
